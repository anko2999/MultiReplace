# MultiReplace — 一括置換ツール

指定フォルダ内のファイルを対象に、**複数の置換ワードをまとめて**置換する Windows 用ツール。

- テキストファイルの中身を置換（文字コード・改行コードを維持）
- Excel ファイル（.xlsx / .xlsm）の **セルの値 / シート名 / コメント・図形内の文字** を選んで置換
- **ファイル名** の置換（中身のみ / 名前のみ / 両方）
- プレビュー（変更なしで結果だけ確認）、バックアップ(.bak)、設定の自動保存

---

## 1. 動作環境・ビルド

| 項目 | 内容 |
|---|---|
| OS | Windows 10 / 11 (x64) |
| 実行に必要なもの | .NET Desktop Runtime 8 以降（9, 10 でも動作）。**これ以外の追加インストールは不要** |
| 言語 | C# (.NET 8, WinForms)。外部ライブラリ（NuGet パッケージ）は使用していない |

### ビルド方法

.NET 8 SDK 以降が入っている PC で `build.bat` を実行する。

```
build.bat
→ dist\MultiReplace.exe （単一 exe）
```

手動なら:

```
dotnet publish MultiReplace.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:DebugType=none -o dist
```

`dist\MultiReplace.exe` だけを配布すればよい（受け取る側は .NET Desktop Runtime 8 以降が必要）。

### ファイル構成

| ファイル | 役割 |
|---|---|
| `Core.cs` | 置換エンジン（テキスト / Excel / ファイル名）。UI に依存しない |
| `MainForm.cs` | 画面 |
| `Program.cs` | エントリポイント |
| `MultiReplace.csproj` | プロジェクト定義 |
| `build.bat` | ビルド用バッチ |

## 2. 使い方

1. **対象フォルダ** を入力（「参照...」ボタン、またはフォルダ / ファイルをウィンドウにドラッグ＆ドロップ）
2. **対象ファイル名** を入力。ワイルドカード（`*` `?`）が使え、`;` で複数指定できる
   - 例: `*.txt;*.csv;data_*.xlsx`
   - 「サブフォルダも対象にする」でサブフォルダ内も探索
   - **除外ファイル名** に指定したものは対象から外す（既定は `*.bak`）。`;` 区切りでワイルドカード可。末尾が `\` のものはフォルダ名の除外（例: `*.bak;*_old.*;.git\;bin\` ）。フォルダ名の除外は、対象フォルダ以下のどの階層のフォルダにも適用される
3. **置換するもの** を選ぶ（後述）。Excel を扱う場合は「Excel の置換対象」も選ぶ
4. **置換ワード** の表に「検索する文字列」「置換後の文字列」を入力（複数行可）
   - 置換後を空欄にすると、その文字列を削除する
   - Excel 等からコピーした 2 列の範囲を、表の上で `Ctrl+V` して一括登録できる
5. **プレビュー（置換しない）** を押して、ログで対象と件数を確認
6. 問題なければ **置換を実行**（確認ダイアログあり）

実行中は **中止** ボタンで中断できる（処理済みのファイルは元に戻らない。バックアップから戻す）。

### 画面の各項目

| 項目 | 説明 |
|---|---|
| 置換するもの | 「ファイルの中身」「ファイル名」「ディレクトリ名（フォルダ名）」。**複数を同時に選べる**（少なくとも1つ必要） |
| 拡張子もファイル名置換の対象にする | オフ（既定）なら拡張子を除いた部分だけを置換。オンなら `.txt` → `.md` のような拡張子変更も可能（ファイル名のみに影響。フォルダ名には関係しない） |
| Excel の置換対象 | セルの値 / シート名 / コメント・図形・グラフ内の文字（複数選択可）。中身を置換するモードのときだけ有効 |
| 正規表現を使う | オンにすると、検索する文字列を正規表現として扱う（置換後は `$1` `${名前}` が使える）。詳細は「3. 置換ルールの仕様」 |
| 大文字/小文字を区別する | 既定オン。オフにすると `abc` が `ABC` にもマッチ。ファイル名・シート名にも適用 |
| `\n` `\t` などのエスケープを使う | オンにすると、置換ワード中の `\n`(LF) `\r`(CR) `\t`(タブ) `\\`(バックスラッシュ) を実際の文字として扱う。正規表現モードでは検索側は正規表現が解釈するので、**置換後の文字列だけ**が対象 |
| バックアップ(.bak)を作る | 既定オン。中身を書き換えるファイルを `元の名前.bak` として保存してから上書き |

## 3. 置換ルールの仕様

- **同時置換**: 全ての置換ワードを 1 回のスキャンで同時に適用する。したがって
  - `A→B` と `B→A` を同時に登録すれば **入れ替え** ができる（`AAA and BBB` → `BBB and AAA`）
  - 置換結果が別のルールに再度マッチすることはない（連鎖しない）
- 複数のワードが同じ位置にマッチする場合は **長い検索文字列が優先** される（`ab` と `abc` があれば `abc` を優先）
- 検索文字列が空の行は無視する。同じ検索文字列が複数あれば上の行を採用する

### 文字列モード（既定）

- 検索文字列を **文字列そのまま** で比較する（`.` `*` などもそのままの文字として扱う）
- 複数のワードが同じ位置にマッチする場合は **長い方を優先**（上の「同時置換」を参照）

### 正規表現モード

「正規表現を使う」をオンにすると、検索する文字列が .NET の正規表現になる。ファイルの中身・Excel のセル・数値セル・コメント・シート名・ファイル名の **すべて** に適用される。

| 項目 | 内容 |
|---|---|
| 後方参照 | 置換後に `$1`, `${名前}`, `$&`（マッチ全体）が使える。`$` 自体を出したいときは `$$` |
| 例 | `(\d+)円` → `$1 JPY` ／ `(?<a>foo) (?<b>bar)` → `${b} ${a}` ／ `report_(\d+)` → `rpt-$1` |
| 複数ルール | 同時置換は文字列モードと同じ。同じ位置に複数のルールがマッチした場合は **上の行を優先**（長さ優先ではない） |
| 行頭・行末 | `^` `$` は **行単位** で働く（Multiline）。`.` は改行にマッチしない |
| 大文字/小文字 | 「大文字/小文字を区別する」に従う |
| 検索パターン内の `\1` | 複数ルールをまとめて処理する都合で、パターン内の番号付き後方参照（`(a)\1`）は正しく動かない。**名前付きグループ `(?<x>a)\k<x>` を使う**（置換後の `$1` は問題なし） |
| 空文字にマッチするパターン | `^` `\d*` のように空の文字列にマッチするものは、無限に増えるため **エラーにして実行しない** |
| 不正な正規表現 | 実行前にエラーダイアログを出す |
| タイムアウト | 1回のマッチが 10 秒を超えると（バックトラックの暴走など）、そのファイルはエラーにして次へ進む |

> **CRLF のファイルでの `$`**: `$` は `\n` の直前にマッチするため、改行が CRLF のファイルでは `\r` が間に挟まる。行末にマッチさせたいときは **`\r?$`** と書く（例: `[ \t]+\r?$` → 空欄、で行末の空白を削除）。`\s*$` のように `\s` が改行まで食べるパターンは、改行コードを壊すので避ける。

## 4. テキストファイルの置換

### 文字コードの扱い（元のまま維持）

読み込み時に自動判別し、**同じ文字コードで書き戻す**。

| 判別方法 | 文字コード | 書き戻し |
|---|---|---|
| 先頭が `EF BB BF` | UTF-8 (BOM 付き) | BOM を維持 |
| 先頭が `FF FE` | UTF-16 LE (BOM 付き) | BOM を維持 |
| 先頭が `FE FF` | UTF-16 BE (BOM 付き) | BOM を維持 |
| 上記以外で UTF-8 として正しく読める | UTF-8 (BOM なし) | BOM なしで維持（ASCII のみのファイルもここ） |
| 上記以外で UTF-8 として読めない | Shift_JIS (CP932) | CP932 で維持 |

- 置換後の文字が元の文字コードで表せない場合（例: Shift_JIS のファイルに絵文字を挿入）は、**そのファイルを変更せずエラー**にする（文字化けさせない）

### 改行コードの扱い（元のまま維持）

ファイル内容を文字列のまま置換し、改行には手を加えない。CRLF / LF / CR、およびそれらが混在したファイルも、**置換した箇所以外は 1 バイトも変わらない**。

### スキップされるファイル

- 先頭 8KB に NUL バイトを含むファイル（バイナリ扱い）
- 上記の文字コードで読めなかったファイル（EUC-JP, ISO-2022-JP, BOM なし UTF-16 など）
- `~$` で始まる Excel のロックファイル
- 隠し属性・システム属性のファイル（探索対象に含まれない）
- 「除外ファイル名」に一致するファイル・フォルダ内のファイル

> **注意**: EUC-JP など想定外の文字コードは、まれに Shift_JIS と誤判定される可能性がある。重要なファイルはプレビューで確認し、バックアップを有効にしておくこと。

## 5. Excel ファイルの置換

対象は **.xlsx / .xlsm / .xltx / .xltm**。Excel 本体は不要。ファイル内の XML だけを書き換えるので、書式・マクロ・画像・グラフ・条件付き書式などは、置換対象以外そのまま保たれる（Excel で開いて保存し直すわけではない）。

### 置換対象の選択

| 対象 | 置換される場所 |
|---|---|
| **セルの値** | セルに入力された文字列（共有文字列・インライン文字列）。テーブル（表機能）の列見出しも、セルとの整合のため同時に置換 |
| **数値セル** | 数値として入力されたセル。Excel 内部で保存されている値の文字列（`123`, `0.5`, `-123.5` など）に対して、文字列と同じように置換する（例: `123` → `456`）。数式セルは対象外 |
| **シート名** | シートタブの名前。**そのシートを参照している数式・定義名・グラフの参照・条件付き書式/入力規則の数式・内部ハイパーリンクも自動で書き換える**（後述） |
| **コメント・図形・グラフ内の文字** | セルのコメント（メモ）、テキストボックス・図形内の文字、グラフのタイトル・軸ラベル等 |

### 数値セルの置換について

- 数値は文字列セルとは別に保存されているため、「数値セル」のチェックが必要（既定でオン）
- **保存されている値の文字列** に対して置換する。表示形式（`1,234` や `2024/1/23` など）ではなく、実際の値が対象
  - `123` → `456` とすると、`123` は `456`、`1234` は `4564`、`-123.5` は `-456.5` になる
  - 日付・時刻はシリアル値（例: `45123`）で保存されているので、桁が一致すると置換される。意図しない変更を避けるため、プレビューで確認すること
- 置換後が数値として不正になる場合（例: `123` → `ABC`、`-123.5` → `-ABC.5`）は、そのセルを **文字列セルに変換** して置換する
- 数式セルの値は置換しない

### リッチテキスト（セル内で書式が混在した文字列）

`旧会`（標準）＋`社名`（太字）のように書式が分かれていても、**書式をまたいだ一致も置換できる**。置換後の文字列は、一致が始まった位置の書式になる。

### シート名の置換について

- 例: `旧会社名一覧` → `新会社名一覧` とすると、`='旧会社名一覧'!A2` は `='新会社名一覧'!A2` に自動で更新される
- 数式中の文字列リテラル（`"旧会社名!"` のような `"..."` 内）は変更しない
- 正規表現モードでもシート名に適用できる（例: `^旧(.*)$` → `新$1`）
- 次の場合は **そのファイルを変更せずエラー** にする
  - 置換後のシート名が 31 文字を超える / 空になる / `\ / ? * [ ] :` を含む / 先頭か末尾が `'`
  - 置換した結果、同じ名前のシートが 2 つできてしまう

### 数式の扱い

- **数式そのもの（式の文字列）や、数式の計算結果として表示される値は置換しない**（「セルの値」「数値セル」は、直接入力された値が対象）
- シート名を置換した場合に限り、参照部分のシート名だけが書き換わる

### 制限事項

- **.xls / .xlsb は未対応**（スキップしてログに表示）。.xlsx に変換して使う
- パスワード保護されたファイル、壊れたファイルはスキップ
- シート名置換で **追従しない参照**: 複数シートにまたがる 3D 参照（`Sheet1:Sheet3!A1`）、ピボットテーブル、外部ブックリンク、図形の「セルへのリンク」、VBA コード内のシート名
- Excel で開いているファイルは書き込めずエラーになる（閉じてから実行）
- 数式の計算結果キャッシュ、グラフのキャッシュ値は更新しない（Excel で開くと再計算・再描画される）

## 6. ファイル名の置換

- 「置換するもの」の「ファイル名」にチェックを入れる
- 対象は **「対象ファイル名」のパターンに合致したファイル**
- 既定ではファイル名の **拡張子を除いた部分** に置換ワードを適用する（「拡張子もファイル名置換の対象にする」で拡張子も対象にできる）
- 「ファイルの中身」も選んでいる場合は **中身 → ファイル名** の順に処理する
- 次の場合は **名前を変更せずエラー** としてログに表示する（中身の置換は行われる場合がある）
  - 変更後のファイル名が Windows で使えない（空 / `\ / : * ? " < > |` を含む / 末尾が空白かピリオド）
  - 同じフォルダに同名のファイルが既にある
  - 同じ実行内で、別のファイルの変更後の名前と重複する（`a→b` と `b→a` のような入れ替えも重複扱い）
- ファイル名の変更にバックアップは作らない（元の名前はログに残るので、必要なら控えておく）

---

### 処理速度について

- Excel は本体を起動せず、ファイル内の XML を直接処理する
- 置換ワードに一致するものが無いシートは解析自体を省略し、変更が無いファイルは書き込まない
- 中身だけの置換は、複数ファイルを並列で処理する

### ディレクトリ名の置換

- 「置換するもの」の「ディレクトリ名（フォルダ名）」にチェックを入れる（ファイルの中身・ファイル名と同時に選べる）
- 対象は、対象フォルダの **中にあるフォルダ**。対象フォルダ自身の名前は変更しない。「サブフォルダも対象にする」がオフなら、直下のフォルダだけが対象
- 置換ワードは **フォルダ名全体** に適用する（`v1.2` のようにピリオドを含む名前も、拡張子扱いせず全体が対象）。「対象ファイル名」のパターンは、フォルダ名には適用されない
- **除外ファイル名** はフォルダ名にも適用される。`.git\` のようにフォルダ名で除外すると、そのフォルダ自身と中のサブフォルダは変更されない（ファイルの置換も行われない）
- 処理順:
  1. ファイルの処理（中身 → ファイル名）をすべて終える
  2. そのあと、**深い階層のフォルダから順に** 名前を変更する（親フォルダの名前が変わっても、先に処理した子フォルダのパスが無効にならない）
  - ログに表示されるパスは **変更前** のもの
- 名前を変更せずエラーにするケースはファイル名と同様（不正な名前 / 同名のフォルダ・ファイルが既にある / 他の変更後の名前と重複）。ジャンクション・シンボリックリンクはスキップする
- 大文字小文字だけの変更（`abc` → `ABC`）も可能
- フォルダの変更にバックアップは作らない。実行前にプレビューで確認すること

## 7. ログと設定

### ログ表示

| 表示 | 意味 |
|---|---|
| `[置換予定]` | プレビューで、実行すると変更されるファイル（件数 / 変更後のファイル名） |
| `[フォルダ名置換予定]` / `[フォルダ名置換]` | ディレクトリ名の変更（プレビュー / 実行）。表示は変更前のパス |
| `[置換]` | 実行して変更したファイル |
| `[スキップ]` | 対象外の形式や読み込めないファイル |
| `[エラー]` | 書き込み失敗・ファイル名の衝突・不正なシート名など |

> 「中身だけを置換」するときは、複数ファイルを **並列で処理** するため、ログの順序は実行ごとに前後することがある。ファイル名の変更を伴うときは、衝突判定のため順番に処理する。

変更のなかったファイルは個別には表示せず、最後の集計（対象ファイル数 / 変更ファイル数 / 置換箇所数 / ファイル名変更数 / スキップ / エラー）にだけ含める。

### 設定の保存

終了時に入力内容（フォルダ・ファイル名・置換ワード・オプション）を自動保存し、次回起動時に復元する。

```
%APPDATA%\MultiReplace\settings.json
```

## 8. 安全に使うために

1. 初回は **必ずプレビュー** で対象と件数を確認する
2. **バックアップ(.bak)** は既定でオン。重要なデータは別途コピーも取っておく
3. 探索対象が広いとき（`*` や `*.*`）は、意図しないファイルを書き換えないようファイル名パターンを絞る
4. フォルダ名の変更は、ファイルの中身や他のプログラムが持っているパスに影響する（ショートカット、設定ファイル内のパス、Git 管理下のフォルダなど）。変更前に確認すること
5. `.bak` ファイルは、既定の除外ファイル名 `*.bak` で対象から外れる。除外欄を空にすると対象に含まれるので注意する
